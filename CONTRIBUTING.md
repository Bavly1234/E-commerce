# Contributing

Thank you for your interest in contributing to this Angular e-commerce project.

## How to contribute

1. Fork the repository.
2. Create a new branch for your work:
   ```bash
   git checkout -b feature/your-feature-name
   ```

```
3. Make your changes and commit them with a clear message.
4. Push your branch to your fork.
5. Open a pull request against the `main` branch.

## Code quality

- Keep code readable and consistent with the existing style.
- Run `npm run format` before committing.
- Test your changes locally using `npm test`.

## Issues and feature requests

If you find bugs or want to propose improvements, please open an issue with a clear description and reproduction steps.
```
